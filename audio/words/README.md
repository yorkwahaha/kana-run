# 完整單詞錄音（選用）

## 為什麼需要這個資料夾

單字題（挖空題）預設把讀音拆成一個個假名，依序播放：

    り・ゆ・う  →  りゆう.mp3 → ゆう.mp3 → う.mp3

三段獨立播完會聽起來像三個分開的音，不是一個詞。對照挖空時
「靴　○つ」需要聽出整個詞的節奏才有辦法判斷。

在這個資料夾放入**整個單詞**的錄音，就會優先使用那一段。

## 命名規則

檔名 = 該詞的**平假名讀音**，副檔名任選其一：

    りゆう.ogg / りゆう.mp3 / りゆう.wav / りゆう.m4a

查找順序為 `ogg → mp3 → wav → m4a`，找到第一個就停。

注意讀音必須是平假名。`KanaDB` 裡的詞條讀音欄本來就是平假名，
但如果自行加入詞庫時寫成片假名，這裡就會查不到。

## 錄音建議

- 單一原生母語者，避免多人合錄造成音色跳動
- 乾淨無背景音，音量峰值約 −6 dBFS
- 保留自然的長音（`りゅう`、`びーる` 這類）
- 詞與詞之間不需要間隔音

## 生效方式

放進去之後重新啟動遊戲即可，不需要改任何程式碼。
逐音 fallback 永遠保留：沒有整詞錄音的詞會照舊用假名接接，
兩種可以混著用。
