# 完整單詞錄音（選用）

## 為什麼需要這個資料夾

單字題（挖空題）只播放這個資料夾裡的整詞錄音。
五十音音檔不再被接成一個詞。對照挖空時「靴　○つ」
需要聽出整個詞的節奏才有辦法判斷。

## 命名規則

檔名 = 該詞的**平假名讀音**，副檔名任選其一：

    りゆう.ogg / りゆう.mp3 / りゆう.wav / りゆう.m4a

查找順序為 `ogg → mp3 → wav → m4a`，找到第一個就停。

注意讀音必須是平假名。`KanaDB` 裡的詞條讀音欄本來就是平假名，
但如果自行加入詞庫時寫成片假名，這裡就會查不到。

## 錄音建議

- 單一原生母語者，避免多人合錄造成音色跳動
- 乾淨無背景音，音量峰值約 −6 dBFS
- 保留自然的長音（`りゅう`、`びーる` 這類）
- 詞與詞之間不需要間隔音

## 生效方式

放進去之後要重跑 `python tools/gen_manifest.py`，整詞才會被打進網頁版。
沒有對應錄音的詞不會出成單字題的語音（題目仍會出現，只是沒有整詞可播）。
